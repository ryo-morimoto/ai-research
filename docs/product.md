# ai-research：何のためのシステムか

（旧 docs/01 §0・§1・§4 の現在形。制約の一覧は spec/constraints.ts が正で、docs/generated/SPEC.md に生成される。改訂の経緯は adr/archive/01 の冒頭にある）

## やりたいこと

**調査にかかる時間を短くする。そのために、時間を食っている原因を取り除くシステムを作る。**

- **どの機械・どの会話・どの作業場所から依頼しても、同じ依頼には同じ結果が同じ速さで返る。** 機械ごとに記憶が違えば調べ直しになり、会話の文脈を一歩ごとに運べば1ステップが重くなる。「同じ」は利用者が違いを意識しなくてよいという意味で、LLM に送る文字列の一致までは求めない（揺らぎの扱いは下記）。
- **論文・研究の知見を問う調査は、一次資料（書誌・抄録、読めれば本文）まで届く。** 解説記事や百科事典を一次資料の代わりにしない。
- **調べものは、道具を指定しなくてもこのシステムの経路を通る。** 速さ（再利用）・確かさ（照合）・一貫性・外部への配慮は、この経路の上でしか保証できない。通らなかった結果はそれと分かるようにする。

## 成功の物差し

| 物差し | 目標 |
|---|---|
| 依頼から最初の結果まで | 60秒以内（P95） |
| 最初の結果から続きまで | 180秒以内（P95） |
| 作り直し・調べ直しの時間の割合 | 下がり続ける |
| 何も進んでいない時間の割合 | 下がり続ける |
| 機械・会話・作業場所による結果の違い | 0件 |

## 範囲

- 使う人：利用者本人1人。機械は複数の PC とスマートフォン。
- 面：Claude Code（ターミナル・デスクトップ・クラウド）と Claude のチャット（ブラウザ・デスクトップ・スマートフォン）。
- 対象：AI エージェントで行う調査（新しい概念と再調査の両方）。

### やらないこと

- 出典そのものの誤りを見抜くこと（出典を示して利用者が気づけるようにはする）
- 成果物の後工程（スキル化・長いレポート化）の高速化
- 複数人での共有

## 制約の分け方

依頼から結果までの時間はどの瞬間も W（無駄な作業）・S（必要な作業の遅さ）・P（停滞）のどれかに当たる。守るものは Q（確かさと一貫性）・U（利用者の負担）・E（外部への影響）・R（資源）、見える化は V/C。一覧と検査は `docs/generated/SPEC.md`。

### 「結果が同じ」の定義

主張・出典・確認状態の組で比べる。次だけは違いに数えない（どれも理由が結果に表示されることが条件）：(1) 出典そのものが変わった、(2) 時間の打ち切りで確認が済まなかった（Q-04）、(3) モデルの出力の揺らぎ（会話のモデルの違いを含む。台帳には原文の抜き書きしか入らないので、持ち込まれる事実は変わらない）。

## 制約どうしの緊張関係（優先順位の決定）

| 緊張 | 優先 |
|---|---|
| 60秒で最初の結果（W-01）と確認済の主張（Q-01） | 60秒。間に合わない主張は「未照合」として出す |
| 再利用の速さ（W-03）と取り直しと同じ結果（Q-02） | Q-02。照らし直しが間に合わなければ「未照合」 |
| 抜き書きを短く（E-01）と照らし直しの頑健さ | E-01。短い抜き書きで成り立つ手段を選ぶ |
| 記憶を1か所（Q-05）と常駐サーバーなし（R-02） | Q-05。保守の要らないマネージドな置き場所で両立 |
| 記憶に届かないときの調査 | 止めない。持ち込みを使わず全て「未照合」、「届かなかった」と明記 |
| 会話で依頼を補う（W-02）と文脈を事実にしない（Q-06） | 補ってよい。「解釈した問い」として示す。保存は原文に限る |
| 経路の強制（U-03）と利用者の明示 | 明示を優先。経路外で調べ Q-07 で示す |
| 経路の強制（U-03）とシステムに届かないとき | 調査は止めない。フックは止めない側に倒れる |
| 1つの台帳（Q-05）と話題の混ざり | 名前空間は作らない。関連の下限（S-06）で絞る |
| 一次資料（Q-08）と規約・頻度（E-02) | 規約が許す書誌・抄録 API を使う。本文は公開の版だけ |
| 量を減らす（S-06）と打ち切りを示す（Q-04） | 答えに影響したものは1件ずつ、他は件数と URL |
| 軽い往復（U-04）と状態の表示（Q-01・Q-06） | 状態は出典の後ろに短く。解釈した問いは補ったときだけ |
| 経路率（U-03）と負担（U-01） | U-01。アカウント1回の登録で届く仕組みだけ |
| その場の好みと一貫性（Q-06） | 常に効かせる方針はハブに置く。その場の好みは依頼文に書かれたときだけ |
